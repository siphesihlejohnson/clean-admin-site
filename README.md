# clean-admin.com

Landing page for CleanAdmin, hosted on GitHub Pages at https://www.clean-admin.com.

- `index.html`: the landing page (WhatsApp is the main call to action)
- `privacy.html`, `terms.html`, `404.html`: supporting pages
- The enquiry form posts to a Google Apps Script web app that saves rows to the CleanAdmin Google Sheet
- `CNAME`: custom domain for GitHub Pages
